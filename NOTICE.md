# Third-party components

SayKey is an independent project. It is not affiliated with or endorsed by
CapsWriter-Offline; it only talks to a speech-recognition server that the user
runs themselves.

The optional desktop adapter reads code from the user's installed
[CapsWriter-Offline](https://github.com/HaujetZhao/CapsWriter-Offline).
That source code is not included or relicensed in this repository. Its original
license remains applicable. Model files and personal word lists are not included.

Optional Python dependencies: [pypinyin](https://github.com/mozillazg/python-pinyin)
and [RapidFuzz](https://github.com/rapidfuzz/RapidFuzz). See their distributions for
their respective license notices.

The bundled compact full-pinyin dictionary is generated by
`scripts/build_pinyin_lexicon.py` from jieba 0.42.1's public word/frequency
dictionary and pypinyin 0.55.0's public pronunciation data (both MIT), with
frequencies blended with the everyday-language word lists of wordfreq 3.1.1
(data CC BY-SA 4.0), plus the 6,000 most used idioms from THUOCL (MIT) read
with chinese-xinhua's idiom pronunciations (MIT). The generator reads only
explicit public package data; it never reads the user's CapsWriter vocabulary.
Generated data: 27,454 pinyin keys / 42,869 word entries, about 2.2 MB in
three JSON files. Jieba source dictionary SHA-256:
`7197c3211ddd98962b036cdf40324d1ea2bfaa12bd028e68faa70111a88e12a8`.

The bundled word-suggestion tables (about 1.6 MB) are generated by
`scripts/build_suggestions.py` from public data only; they never contain
anything a user typed. Chinese (`suggest-zh.txt`: 16,000 words with up to 8
followers each, idiom endings and about 12,900 歇后语) is derived from the
Google Books Ngram Viewer exports, version 20200217, simplified Chinese,
licensed CC BY 3.0, reweighted toward everyday language with wordfreq 3.1.1
(data CC BY-SA 4.0), with idioms from THUOCL (MIT) and 歇后语 from
pwxcoo/chinese-xinhua (MIT). English (`suggest-en.txt`,
`suggest-en-words.txt`) is derived from the frequency dictionaries shipped
with symspellpy 6.10.2 (MIT), which SymSpell built from Google Books Ngram
data (CC BY 3.0) and SCOWL (permissive, notice required), ordered by
wordfreq's English frequencies. Because wordfreq's data is CC BY-SA 4.0, the
generated suggestion and pinyin tables are offered under CC BY-SA 4.0 as well.
All notices are bundled in `ios/Shared/ThirdPartyNotices.txt`.

The build uses [XcodeGen](https://github.com/yonaskolb/XcodeGen) and GitHub's
official Actions. The app uses UIKit and SF Symbols supplied by Apple.

This is an independent experiment. It does not include Typeless code, logo,
assets, service access or subscription functionality.
